# Contributing to SIA public research

SIA's production runtime is private, but useful contributions to the public research repository are welcome.

## Good contribution areas

- benchmark cases that test agent reliability
- evaluation methodology
- reproducible failure cases
- architecture discussion
- documentation improvements
- safe examples that do not expose proprietary implementation details

## Before contributing

Please keep proposals focused on reliability, verification, tool use, recovery, interoperability, or evaluation.

Do not submit private code, credentials, model secrets, proprietary prompts, or confidential datasets.

## Benchmark contributions

A good benchmark contribution should explain:

- the failure mode being tested
- expected behavior
- pass/fail criteria
- why the case is model-agnostic where possible

## Security-sensitive reports

Do not publish exploitable security details or secrets in public issues.
